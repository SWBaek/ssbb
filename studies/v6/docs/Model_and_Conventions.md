# V6 모델 및 사양 해설

## 1. 변경 불가 입력과 용량 불일치
`specification.json`을 최우선 기준으로 사용한다. 확정 입력은 230 Vac, 48 Arms, 피크값 dq, PWM/제어 각 62500 Hz, 두 주기 모두 16 μs이다. 230×48=11040 VA이며 제품급 명칭 11520 VA와 다르다. 본 모델은 230 V와 48 A를 사용하고 그 결과를 11.52 kVA 성능으로 환산하지 않는다. 명판 정격 전압의 확인은 남은 사양 조치이다.

## 2. dq 지령
모든 Case 입력은 `id_peak_a`, `iq_peak_a`이다. RMS 입력을 받는 함수는 없다. 시험 격자를 읽기 편하도록 [0,4,8,16,32,48] A 실효값에 대응하는 피크값을 산출하지만, 저장·실행 인터페이스는 항상 Peak A이다.

v=√2 V₁ cosθ, iα=id cosθ−iq sinθ, iβ=id sinθ+iq cosθ.

id=iα cosθ+iβ sinθ, iq=−iα sinθ+iβ cosθ.

P₁=V₁ id/√2, Q₁=−V₁ iq/√2. 여기서는 +Iq를 진상전류로 정의한다. 실제 CAN의 Q 부호와 일치했다고 주장하지 않는다. Theta는 SOGI-PLL 내부 동기각이며 외부 명령 변수가 아니다.

기본파 전류 지령 한계는 sqrt(id²+iq²)≤√2×48=67.88225099 Apeak이다. 한계를 넘는 조건은 숨겨서 축소하지 않고 입력 오류로 거부한다. 출력 실제 RMS에는 고조파·스위칭 리플도 포함되므로, 기본파 지령 제한과 실제 RMS≤48 A 판정은 별개이다. 보호동작을 포함한 동적 전류 제한 로직은 본 모델에 포함되지 않는다.

## 3. 두 클록과 추가 지연
PWM n: [16n,16(n+1)) μs. ADC와 제어 연산: 16n+8 μs. 결과는 다음 경계 16(n+1) μs에 반영된다. 기본 샘플→적용 지연은 8 μs이며 이것은 추가 가정이다. 제어 연산은 매 PWM마다 한 번이다.

추가 지연 민감도에서는 결과를 1 또는 2개의 PWM 주기만큼 더 늦게 적용한다. 이 경우에도 제어 연산 자체는 매 16 μs마다 수행한다. 모든 명령을 FIFO로 보존하며 다음 샘플이 이전 미적용 명령을 덮어쓰지 않도록 검증한다. 위상 예측 16 μs는 nominal 지연+평균 hold 위치의 근사이며 추가 지연 시험에서 다시 튜닝하지 않는다.

## 4. 회로 모델과 적분
출력 전압은 (HF pole − LF pole)×Vdc이다. HF는 중앙정렬 PWM과 양쪽 turn-on dead-time을 상태기계로 실행한다. 대기 중 turn-on 이벤트는 PWM 경계를 넘어 유지하며, 반대 지령이 먼저 오면 기존 이벤트를 취소한다. 두 gate가 동시에 켜지는 상태는 정의하지 않는다.

LF 레그는 기준 모델에서 브리지 전압 명령의 부호로 선택한다. 계통전압 부호로 LF를 고정하는 대안은 별도의 구조 검증에서만 사용한다. 이 차이는 V2G 무효전력 동작에 중요하다. 실제 LF 영교차 전환·blanking·hysteresis가 구현됐다는 의미는 아니다.

L di/dt = u−vg−Ri. 각 gate 이벤트 및 균일 출력 구간을 나누고, 각 구간 중앙값으로 vg를 고정한 RL 해와 1차 센서 해를 계산한다. vg의 구간 고정 근사오차는 2/1/0.5 μs 세분화로 확인한다. dead-time 중 다이오드만 도통할 때 전류 영교차 후 역방향 비물리 전류가 생기지 않도록 zero-clamp를 적용한다.

본 모델은 일반화된 단상 AC단 참조 모델이다. CLLC, DC-link 저장에너지 제어, EMI 필터, 소자 출력정전용량, 열, 실제 양산 SW와의 대응은 미검증이다. 이상적인 강성 DC 전원은 Q 운전의 순간 에너지 교환을 허용한다. 실제 배터리/CLLC가 그 동작을 지원한다는 증거는 아니다.

## 5. 디지털 제어
기본 dq PI, 계통전압 전향보상과 ωL 교차결합 보상을 사용한다. 기본 전류 설계 파라미터 800 Hz와 PLL 설계 파라미터 15 Hz는 가정값이지 측정한 폐루프 대역폭이 아니다. 실제 안정여유는 별도 평가 대상이다.

개선안은 전류오차에 대해 3·5·7차 중 선택한 준공진 피드백을 더한다. 중심 주파수는 60 Hz의 배수인 180/300/420 Hz이다. Gₕ(s)=2Krωc s/(s²+2ωc s+ωh²). 각 중심에서 prewarp한 bilinear 변환을 16 μs로 수행한다. 각 출력은 ±30 V, dq 적분상태는 ±150 V로 제한하며 제한 발생 여부를 저장한다. 주파수 변화 시험에서도 선정한 공진 계수를 고정한다.

## 6. 전류 측정과 판정
마지막 15개 계통 주기에서 전류 원시 파형을 직접 투영해 기본파 및 2~40차를 계산한다. 기준 60 Hz에서는 0.25 s 구간이며, 2 μs 출력 간격일 때 약 125000개의 시간 표본이다. 시간 표본 수는 실험 반복 수가 아니다.

THD₂₋₄₀=100×sqrt(Σ₂⁴⁰ Ih²)/I₁. 40차까지의 절대 고조파 RMS와 정격전류 대비 비율도 별도로 저장한다. 후자의 제한된 대역 지표를 IEEE 1547의 TRD와 동일시하지 않는다. THD 5%는 이번 설계 비교의 잠정 기준이다. 북미 인증 적합성은 판정하지 않는다.

정상성은 마지막 두 주기의 1~7차 Fourier 계수 차이의 실효값으로 평가한다. 비동기 PWM 리플 자체를 한 계통 주기씩 빼지 않는다. RMS와 피크, dq 추종, 포화, 정상성의 동시 만족을 종합 만족으로 정의한다. 경계 근처의 수 mA 초과는 수치 판정 결과이며 계측 불확도가 없는 실제 제품 부적합 판단으로 확장하지 않는다.
