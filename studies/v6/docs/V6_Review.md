# V6 사양·논리 검토 및 변경 기록

## 1. V5 처리
V5는 최신 사용자 사양이 아닌 32 Arms, 제어 32 μs, RMS 환산 외부 지령을 사용했다. V6의 성능 근거로 사용하지 않는다. V5 원본은 이력상 보존하며, 새로운 기준값과 새로운 계산 결과만 V6에 사용했다. 이전의 초기 THD나 개선량에 맞추는 보정, 정격비를 곱하는 환산은 수행하지 않았다. 표현을 위한 PowerPoint 도형·표 생성 유틸리티만 재사용했다.

## 2. 최상위 사양
| 항목 | 고정값 | 검증 |
|---|---|---|
| 기준 계통전압 | 230 Vrms | 사양 파일 및 실행 전 assertion |
| 정격 전류 | 48 Arms | dq 벡터 입력 검사 및 실제 RMS 판정 |
| 외부 dq 지령 | 피크값 A의 DC 지령 | 변환 왕복·P/Q 부호·저장 지령 검사 |
| PWM | 62,500 Hz, 16 μs | 전 실행의 PWM 주기 수 |
| 제어 | 62,500 Hz, 16 μs | 전 실행의 제어 횟수, PWM과 1:1 |
| 제품급 명칭 | 11.52 kVA급 | 사용자 표현으로 보존 |
| 기준점 계산 용량 | 11.04 kVA | 230×48=11,040 VA |

11.52 kVA와 230 V×48 A는 동시에 같은 산술값이 될 수 없다. V6는 240 V 또는 50.087 A로 입력을 바꾸지 않았다. 제품 명판 전압 및 용량 명칭의 최종 확인이 필요하다.

## 3. V6에서 수행한 검토
- 사양, 시험조건, 후보, 선정 규칙을 먼저 고정하고 해시를 저장했다.
- 외부 API는 id_peak_a / iq_peak_a를 사용한다. RMS 환산 수치는 시험 격자 설명에만 사용했다.
- 기본 8 μs 샘플→적용 지연은 확정값이 아닌 모델 가정이다. 추가 지연 시험에서도 제어는 16 μs마다 실행된다.
- FIFO가 미적용 명령을 덮어쓰지 않는지 모든 실행의 명령 출처 인덱스로 확인했다.
- PWM 경계에서 대기 중 turn-on 이벤트를 보존하고, 취소 및 다이오드 영전류 전환을 검토했다.
- 현재 유효전류·무효전류 부호는 모델 규약이며 실제 고객 신호 정의로 확정하지 않았다.
- 북미용 60 Hz는 추가 가정이다. 사용자 확정 주파수 62.5 kHz와 구분했다.
- 48 Arms는 기본파 지령이 아닌 전체 파형 RMS에도 적용한다. 기본파 지령이 48 Arms에 해당해도 고조파·리플 때문에 실제 RMS가 이를 넘을 수 있다.
- 전류 허용값 75 Apeak, THD 5%, 추종·포화·정상성 한계는 연구용 판정 가정이다. 고객 승인값으로 표현하지 않았다.
- 47개는 9개 선정조건과 38개 선정 미사용 조건의 합계다. 이 세 수를 더하지 않는다. 전압 24개, 편차 24개, 구조 6개도 목적과 분모를 구분한다.
- 결정론적 결과에 가상 반복오차, p-value, 공정능력 지수, 양산 불량률을 부여하지 않았다.
- 선정을 마친 뒤 추가 검증 결과를 보면서 후보를 다시 조정하지 않았다.
- 개별 고조파·DC 성분을 별도로 저장한다. THD 감소를 모든 주파수 성분의 감소 또는 DC 주입 규격 만족으로 확대하지 않았다.

## 4. 남은 문제와 최종 판단
THD는 기준 47개에서 모두 잠정 기준을 만족했다. 그러나 순수 Q 정격 2조건은 실제 RMS가 약 2.3~2.5 mA 초과해 엄격한 연구 판정에서 미달이다. 이 작은 차이를 실제 HW 불합격으로 단정하지 않는다. 계측 오차 및 허용공차의 실제 근거가 없다.

편차 검증은 3조건에서 실제 RMS가 한계를 초과했다. LF 레그를 계통전압 부호로 고정하는 구조 대안은 6개 중 4개에서 포화 판정 미달이다. 실제 LF 전환 로직을 확인하지 않고 모델의 기준 구조 결과만 제품에 적용하면 안 된다.

기준 모델의 전압 명령 부호형 LF 전환, 강성 DC-link, 회로값, 검출계, 스위치 이상화는 모두 실제 회로와 대조가 필요하다. HF/LF 모델, 디지털 필터 단독 안정성, 유한 시간 응답의 확인은 전체 비선형 폐루프 안정성이나 인증시험을 대신하지 않는다.

q축 반전 시험에서는 선정 제어의 관측 정착이 더 늦어졌다. 후처리의 중심 정렬 1주기 이동평균이 포함된 지표이며, T04의 약 8.34 ms는 관측 하한이다. OEM 규격의 정착시간으로 사용할 수 없다.

따라서 완료 수준은 **새로운 사양을 반영한 참조 수치모델, 후보 선정 및 잔여 문제 확인**이다. 실제 제품 적용, 인증 및 사내 BB 승인 완료가 아니다.

## 5. 기존 11개 보고서와의 비교
| 참고자료 | 반영한 구성 | V6에서 그대로 따르지 않은 내용 |
|---|---|---|
| LDC Snubber | 변경 가능한 인자와 효율 등 부작용을 함께 검토 | 계산·실측의 혼합 또는 정의가 다른 값의 단일 집계 |
| OBC CLLC | 해석 경로, 요인설계, 선정값의 추적 | 실측 파라미터에 기반한 신뢰도를 V6에 승계하지 않음 |
| DC CAP | 목적 지표가 좋아도 부작용이 있으면 적용을 보류 | THD만 만족했다고 종합 적합으로 처리하지 않음 |
| Heatsink | 가정과 CAE 최적안·후속 시험을 구분 | 기존 시험과의 보정이 V6에도 존재한다고 표현하지 않음 |
| Tub Outer | 설계단계 모델 기반 제안과 적용 범위를 명시 | 제품 실물 성능의 입증으로 확대하지 않음 |
| GNSS | 현 수준·인자 영향·확인시험·관리의 연결 | 정의가 달라지는 목표·단위를 복제하지 않음 |
| TIG 용접 | 변경 불가능한 원인과 실행 가능한 대안을 구분 | 고객 판정 기준을 임의 가정으로 확정하지 않음 |
| HONDA 용접 | 핵심 지표를 좁히고 표준화 문서로 연결 | 실제 양산 불량률·재무 효과를 새로 만들어 넣지 않음 |
| NFC | 물리적 경로와 설계 변경을 연결 | 망소/망대 또는 상·하한의 모호한 표현을 따르지 않음 |
| HMI SW | SW 변경 내용과 업무 성과를 구분 | 검정명과 다른 통계 결과 또는 근거 없는 공수 환산을 사용하지 않음 |
| 디스플레이 | 실험 범위·제약·관리 항목을 명시 | 실험 오차 모형 없는 F 검정·신뢰구간을 형식상 추가하지 않음 |

원본의 흰 배경, 회색 제목띠·표, DMAIC 표시, 시험조건→결과→판단의 문장을 참고했다. 원본 사진·회사 로고·서명·승인은 복제하지 않았다.

## 6. 발행 전 수정한 보고서 품질 문제
데이터 재집계 과정에서 Pandas의 dt 접근자와 열 이름 충돌을 수정했다. 8 Arms 경계의 CSV 반올림 때문에 층별 개수가 달라지는 문제는 저장된 Peak 지령의 환산값을 명시한 자릿수로 분류하여 수정했다. 전체 원시 파형 재계산과 모든 층별 집계를 다시 실행했다. 이는 후처리의 수정이며 모델·판정 기준·선정값이나 시뮬레이션 파형을 바꾸지 않았다.

Define의 시험 구성·판정 설명이 Measure 중간에 등장하던 순서를 정리했다. 용어집과 부록의 띄어쓰기를 보완하고 대표 전류 파형·차수별 결과를 추가했다. 모든 변경 후 최종 PPTX/PDF를 다시 확인한다.
