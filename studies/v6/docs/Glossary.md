# V6 용어집

## 사양·단위

**제품급 명칭**: 11.52 kVA급 사용자가 지정한 명칭. 230×48의 계산값이 아님.

**기준점 용량**: 230 V×48 A=11.04 kVA 해석에 사용한 입력의 피상전력.

**Peak dq**: 피크값 보존 d·q 좌표 DC 값이라는 사실과 RMS 크기 정의는 별개.

**전류 벡터 한계**: sqrt(id²+iq²)≤67.882 Apeak 두 축에 각각 67.882 A를 동시에 지령할 수 없음.

**RMS 전류**: 파형 제곱 평균의 제곱근 스위칭 리플·고조파를 포함한 실제 파형 판정.

**제어주기**: 16 μs PWM 주기와 같은 16 μs. 매 주기 한 번 연산함.

## 신호·전력

**id* / iq***: 외부 DC 전류 지령 [Apeak] d축 유효성분, q축 무효성분.

**Theta**: SOGI-PLL 내부 계통 동기각 외부 유·무효전력 명령이 아님.

**P₁ / Q₁**: 기본파 유효·무효전력 모델의 +Iq는 진상, Q₁=−V₁ Iq/√2.

**Ptotal**: 실제 v(t)i(t)의 구간 평균 고조파가 있으면 P₁과 다를 수 있음.

**I₁ / Iₕ**: 기본파 / h차 고조파 RMS THD 분모와 절대 고조파 전류를 구분함.

**THD₂–₄₀**: 100×sqrt(Σ₂⁴⁰Ih²)/I₁ DC·40차 초과·스위칭 리플 제외. 인증 TRD와 다름.

## 모델·시간축

**HF / LF**: 고주파 / 저주파 bridge 레그 실제 LF 전환 로직은 미확인 상태임.

**dead-time**: 양쪽 스위치 turn-on의 공백 V6의 200 ns는 추가 가정값임.

**ADC 중앙 샘플**: PWM 시작 후 8 μs에서 전류 취득 사용자가 확정한 사양이 아닌 모델 가정임.

**FIFO**: 지연된 명령을 순서대로 적용하는 저장구조 이전의 미적용 명령을 덮어쓰지 않음.

**샘플→적용 지연**: 기본 8 μs / 추가 지연 민감도 별도 확인 추가 지연에도 제어 주기는 16 μs를 유지함.

**수치 시간간격**: 출력2 μs / 비교1·0.5 μs 제어 주기와 별도로 정하는 파형 저장 간격임.

## 제어·판정

**SOGI**: 직교 성분을 생성하는 필터 가상 β축을 구성함. 별도의 실제 AC 전류가 아님.

**dq PI**: 축별 전류오차의 비례·적분 제어 800 Hz는 설계 파라미터이며 측정 대역폭이 아님.

**준공진 피드백**: 특정 고조파 부근의 오차제어 3·5·7차는60 Hz에서180·300·420 Hz.

**Kr / fc**: 공진 이득 [Ω] / 대역 파라미터 [Hz] fc는 PWM 주파수나 계통 기본파가 아님.

**포화 시간비**: 전압 제한이 발생한 평가 비율 전압 오차의 크기나 THD 자체와 다른 지표임.

**종합 만족**: THD 및 모든 보조 조건의 동시 만족 THD 만족 수와 종합 만족 수를 구분함.

## 시험·데이터

**운전조건**: Id/Iq·전압·회로 가정의 조합 1개 실물 시료 1대라는 의미가 아님.

**해석 실행**: 조건 1개에 제어 설정 1개를 적용 초기·선정 비교 시 같은 조건을 2회 실행함.

**선정용 / 미사용**: 47개 중 9개 / 나머지 38개 9+38=47. 38개를 기준 47개에 다시 더하지 않음.

**전압 / 편차 검증**: 서로 다른 목적의 별도 조건 집합, 각 24개 대상 집합이 다른 만족률을 혼합하지 않음.

**시간 표본**: 파형 저장 시각마다 취득한 전류값 15주기의 시간 표본 약 125,000개. 반복시험 수가 아님.

**회귀시험**: 변경 후 같은 기능·성능 시험을 재실행 회귀분석(regression analysis)과 구분함.

## 통계·신뢰성

**DOE**: 인자·수준 조합을 계획한 실험 3인자 각 3수준: 후보 27개, 반응 243개.

**주효과**: 다른 조건을 평균한 수준별 반응의 차이 선정한 범위 내 기술통계이며 p-value가 아님.

**교호작용**: 한 인자의 효과가 다른 인자의 수준에 의존함 그래프 선의 교차 여부만으로 판정하지 않음.

**제곱합 기여도**: 총 반응변동의 요인별 분해 비중 실제 제품의 원인 기여율이나 불량 원인 비율이 아님.

**모델 보정 / 검증**: 입력값 조정 / 별도의 근거와 대조 V6는 기존 THD 값에 맞추어 보정하지 않음.

**%p / %**: 비율의차이 / 상대비율 2.44%−1.00%=1.44%p. 상대 감소율과 구분함.
