## 6. 1. Define / Peak dq 지령과 전력

Theta는 내부 동기각이며 외부 명령이 아님

iα* = id* cosθ − iq* sinθ
P₁* = V₁ id*/√2,   Q₁* = −V₁ iq*/√2
id* / iq* [Apeak] | 기본파 RMS [A] | 240 V 기본파 전력
67.882 / 0 | 48.000 | P₁*=11.52 kW, Q₁*=0
0 / +67.882 | 48.000 | P₁*=0, Q₁*=−11.52 kvar
48.000 / 0 | 33.941 | 48 Arms 운전과 다름
67.882 / 67.882 | 67.882 | 합성 전류 초과로 입력 거부
+Iq는 진상전류로 정의한 모델 규약임. 실제 통신·SW 부호 규약은 별도 확인 필요.

## 41. 부록 / 제어식과 해석식

기본파60 Hz와 Ts=16 μs를 구분하고, 피크값 dq의 변환 및 보상 계수를 명시함.

id = iα cosθ + iβ sinθ;  iq = −iα sinθ + iβ cosθ
iα = id cosθ − iq sinθ
P₁ = V₁id/√2;  Q₁ = −V₁iq/√2
ωh=2π·60·h, ωc=2πfc, K=ωh/tan(ωhTs/2)
D=K²+2ωcK+ωh²
b₀=2KrωcK/D, a₁=2(ωh²−K²)/D, a₂=(K²−2ωcK+ωh²)/D
y[n]=b₀(e[n]−e[n−2])−a₁y[n−1]−a₂y[n−2]
