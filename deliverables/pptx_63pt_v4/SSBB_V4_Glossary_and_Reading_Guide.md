## 2. 시험 수량을 읽는 방법

**운전조건**은 전력 지령, 전압, 부품값 등 물리적 입력 조합이다. **해석 실행**은 운전조건 하나에 제어 조합 하나를 적용해 파형을 계산한 작업이다. **시간 표본**은 파형을 일정 간격으로 저장한 값 하나이다.

- 기준 운전조건 63개 = S* 3수준 × Vac 3수준 × φ 7수준.
- 기준 63개 중 제어 조합을 선택하는 데 사용한 조건은 9개이다. 27개 제어 후보에 동일 9개를 적용하므로 DOE 결과는 243회이다.
- 나머지 54개는 선정 미사용 운전조건이다. 63개와 별도로 더하지 않는다.
- 변동 검증조건 60개는 부품·계통·모델 가정을 바꾼 별도 조건 집합이다. 범위 내 배치 48개와 경계값 조합 12개로 구성한다. 제조 공차의 확률분포를 추정한 표본이 아니다.

예를 들어 M024는 S*=900 VA, Vac=230 V, Vdc=400 V, φ=−30°인 한 조건이다. 같은 조건에 초기·개선 제어를 적용하면 실행은 두 번이지만 운전조건은 하나이다. 실행당 마지막 0.2 s에 저장된 전류 6,400개는 FFT에 쓰는 시간 표본이지 독립 실물 시료가 아니다.

**보고서의 만족률은 대상 집합과 분모를 함께 읽어야 한다.** 63개의 100%, 54개의 100%, 60개의 85%는 서로 다른 질문에 대한 결과이다. 63+54 또는 63+60의 합산 만족률을 개선 성과로 만들지 않는다.

## 3. 지표와 판정의 정확한 정의

전력 지령의 크기는 `S*=sqrt(P*²+Q*²)`이다. 여기서 별표는 지령이라는 뜻이다. 고조파가 포함된 실제 파형에서 계산하는 전압 RMS×전류 RMS와 구분한다. 모델 부호는 P*>0이 계통 송전, φ>0이 지상전류이며 `P*=S* cosφ`, `Q*=S* sinφ`이다. 이 부호를 고객 통신 규약에 그대로 적용하지 않는다.

THD는 전류의 2~40차 RMS 성분을 합성하고 기본파 RMS I1으로 나눈 백분율이다. DC 성분, 40차 초과 성분과 평균모델이 포함하지 않는 스위칭 리플은 계산 범위에 들어가지 않는다. THD≤5%는 이번 연구의 잠정 설계기준이다. 기준조건 만족률 목표95%는 개별 THD 한계5%와 다른 지표이다. 기준조건63개에서는 최소60개가 만족해야95% 이상이다.

**종합 만족**은 THD와 모든 보조 조건의 동시 만족이다. 보조 조건의 내용은 다음과 같다.

| 항목 | 코드와 일치하는 의미 |
|---|---|
| P 추종오차 | 평균 유효전력과 P*의 차이, 단위 W |
| Q1 추종오차 | 기본파 무효전력과 Q*의 차이, 단위 var |
| 전력 오차 한계 | a=max(20,0.02×S*/VA), P오차≤a W와 Q1오차≤a var를 각각 판정. S*=1100VA이면22W와22var |
| 전류 피크 | 정상 평가 구간의 절대 전류 최댓값 <50A |
| 포화 시간비 | 마지막0.2s에서 제한 전 명령이 ±0.95Vdc를 초과한 시간 표본 수 / 구간의 전체 시간 표본 수. 한계0.1% 미만 |
| 주기성 오차 | 연속 두 주기의 같은 위상 전류를 뺀 차이의 RMS. 한계 max(0.005A,0.001I1) 미만 |

**주기성 오차는 ‘각 주기의 RMS를 구한 후 두 RMS를 빼는 값’이 아니다.** 코드의 실제 계산은 `sqrt(mean((i[-640:]-i[-1280:-640])**2))`이다. 예를 들어 크기는 같지만 위상이나 형상이 다른 두 주기는 각각의 RMS가 같아도 파형 차이가 존재한다. V3의 이 항목 설명을 V4에서 정정했다. 코드 및 기존 합부 판정은 바꾸지 않았다.

전류 피크50A를 포함한 모든 한계는 실제 제품 사양으로 확인된 값이 아니다. 주기성 오차가 작다는 것은 계산한 유한 구간에서 파형이 주기적으로 반복된다는 의미이며, 모든 초기조건·교란에 대한 폐루프 안정성 증명은 아니다.

## 4. 통계적 해석을 적용한 단계와 의사결정

### Measure: 평균·최대·만족률과 조건별 그룹 분석

기준조건63개를 S*·Vac가 같은9개 그룹으로 나눈다. 각 그룹은 서로 다른 위상7개를 포함한다. 평균 THD는 해당7개 조건의 동일 가중 평균이고, 최대 THD는 이7개 중 가장 큰 계산값이다. 이 분석으로 낮은 S* 영역에 미달이 집중된다는 것을 확인한다. 제품 간 산포나 제조 로트 변동을 분석한 것은 아니다.

### Analyze: 가정한 오차항 제거와 차수별 반응 비교

모델에 포함한 잔류 전압오차를 제거한 결과와 고조파 피드백을 추가한 결과를 비교한다. 모델에 구현한 왜곡 경로와 제어 대안의 방향을 확인하는 수치 진단이다. 연구자가 모델에 넣은 항을 제거해 변화가 나타났다고 실제 제품 원인을 독립적으로 발견한 것은 아니다.

### Improve: 완전요인배치, 주효과와 교호작용

Kr={8,16,24} Ω, fc={2,5,10} Hz, 적용 차수={{3},{3,5},{3,5,7}}의 모든27개 조합을 계산한다. hmax=7은7차만이 아니라3·5·7차 전체를 의미한다. 동일 조합의9개 데이터는 서로 다른 운전조건이므로 반복오차 추정 자료로 취급하지 않는다.

주효과는 한 인자 수준에서 나머지 인자·운전조건을 동일 가중 평균한 값의 차이이다. 수준별 평균 하나에는3×3×9=81개 계산값이 반영된다. 수준 간 최대−최소는 차수 조합1.213%p, Kr0.734%p, fc0.045%p다. 이는 선택한 수준 범위에서의 평균 반응 차이이며 p-value가 아니다.

교호작용은 Kr 변화에 따른 효과가 차수 조합에 따라 달라지는지 확인한다. Kr8→24Ω일 때 평균 THD 감소는{3}에서0.469%p, {3,5,7}에서0.973%p다. 감소량 차이0.505%p는 두 인자를 함께 고려해야 하는 근거다. 선의 교차 유무가 아니라 효과의 조건 의존성을 본다.

최종 선정은 평균 THD만 보지 않는다. 동일9개 운전조건의 종합 만족 수를 최우선으로 하고, 다음으로 최대 THD, 평균 THD가 작은 조합을 고른다. 동률은 이득·대역 파라미터·최고차수가 작은 순이다. 선정값 Kr24Ω는 시험범위 상단, fc2Hz는 하단이다. 따라서 검토 범위를 벗어난 전역 최적값이나 전체 폐루프 최적점을 의미하지 않는다.

### Improve: 동일 조건의 전후 대응 비교와 만족·미달 전이

같은 Case ID끼리 `초기 THD−개선 THD`를 구한다. 63개가 모두 감소했고 평균 감소는3.612%p다. 이는 동일조건 비교의 기술통계이며 실제 제품 모집단에 대한 대응 t-검정은 수행하지 않았다.

### 제곱합 분해와 미적용 검정

27개 조합 각각의9개 운전조건 평균을 반응값으로 놓고 총제곱합을 A,B,C,AB,AC,BC,ABC로 분해했다. 자유도 합계는2+2+2+4+4+4+8=26이며 남는 오차 자유도가 없다. 따라서 이번 분석에는 F값이나 p-value를 넣지 않았다. 고차 교호작용이 없다는 등의 별도 가정을 세우면 오차 추정이 가능할 수 있으나, 이번에는 그 가정을 임의로 도입하지 않았다. (방법 참고: NIST §5.3.3.9)

수치실험에는 어떤 통계 추론도 사용할 수 없다는 뜻이 아니다. 이번 데이터에는 제품 모집단·표본추출·검정오차 모형이 정의되지 않았으므로 유한집합 기술통계로 한정했다. Gage R&R, 정규성·등분산 검정, t-검정 신뢰구간, Cpk/Z.Bench는 실제 자료 구조와 적용 전제를 확보한 뒤 별도 검토할 항목이다.

## 5. 핵심 정정 사항

- V3의 ‘두 주기의 RMS 차이’를 ‘두 주기 파형 차이의 RMS’로 정정했다.
- P오차와 Q오차를 W·var로 분리했다. 공통 수치한계를 VA 하나로 표시하지 않는다.
- 50Hz는 계통 기본파이며3·5·7차 공진 중심은150·250·350Hz이다. fc=2Hz는 준공진 대역 파라미터이다.
- S를 지령 S*로 명시했다. 왜곡 파형의 측정 피상전력과 혼동하지 않는다.
- 과도응답 표의 전류 피크는 전체 실행 구간에서 계산한 값이다. 정상상태 보조 판정의 피크와 구간이 다르다.
- T3 정착시간의0.0625ms 증가는2Ts의 관측 차이이다. 별도 오차·민감도 근거 없이 유의한 제품 성능 열화라고 단정하지 않는다.

## 6. 용어집

### 1. 시험과 데이터의 단위 (슬라이드 36쪽)

**운전조건 (Case)**: P·Q 지령, 전압, 부품값 등 입력조건 1개 조합. 조건 ID로 식별함. 조건이 다르면 반복 측정이 아님.

**기준 운전조건**: 회로 설정을 고정하고 S*·Vac·φ를 조합한 63개 조건. 실제 제품 시료 63대가 아님.

**제어 선정용 운전조건**: 기준 63개 중 9개. 27개 제어 조합을 비교하는 데 사용함. 9개는 독립 반복실험 횟수가 아님.

**선정 미사용 운전조건**: 기준 63개에서 선정용 9개를 뺀 54개 조건. 63개와 별개로 더하지 않음.

**변동 검증조건**: 부품·환경·모델 가정을 바꾼 별도 60개 조건. 실물 검증 또는 수율 표본이 아님.

**해석 실행 (Run)**: 운전조건 1개에 제어 조합 1개를 적용해 1회 계산함. 같은 조건도 제어가 다르면 별도 실행.

**시간 표본**: 전류 등 파형을 일정 시간간격으로 저장한 값 1개. 6,400개 시간 표본 ≠ 시료 6,400개.

**조건 ID / 실행 ID**: M024 등은 조건 식별자, V2_…는 실행 식별자임. 순서는 시간·생산 로트의 의미가 없음.

### 2. 전력·전류 품질 지표 (슬라이드 37쪽)

**S* [VA]**: √((P*)²+(Q*)²)로 정의한 피상전력 지령의 크기. 왜곡 파형의 실측 Vac×Irms와 구분.

**P* [W] / Q* [var]**: 유효·무효전력 지령. 본 모델은 P*>0이 계통 송전 방향. Q 부호는 고객·통신 규약과 별도 확인.

**φ [°]**: P* = S*·cosφ, Q* = S*·sinφ의 위상각. φ>0은 지상전류. P*=0, Q*≠0은 무전류 상태가 아님.

**Vac [Vrms] / Vdc [V]**: 계통 기본파 전압의 RMS / DC 전압 가정값. Vdc는 동특성을 가진 제어변수가 아님.

**I₁ / Iₕ [Arms]**: 전류의 기본파 / h차 고조파 성분의 실효값. 본 보고서의 기본파 주파수는 50 Hz.

**THD [%]**: 2~40차 전류 RMS 합성값을 I₁로 나눈 비율×100. DC·40차 초과·스위칭 리플은 제외.

**RMS (실효값)**: 제곱값의 평균에 제곱근을 취한 값. 파형 크기를 나타냄. 두 RMS의 차이와 파형 차이의 RMS는 다름.

**%p (퍼센트포인트)**: 두 백분율의 산술 차이. 예: 6.03%−2.42%=3.61%p. 상대 감소율 약 59.9%와 구분함.

### 3. 회로와 제어 (슬라이드 38쪽)

**OBCM / PFC / V2G**: 차량용 충전기 모듈 / 역률 보정 AC단 / 차량→계통 전력 전달. 본 연구는 OBCM 전체 동작 검증이 아님.

**평균 AC단 모델**: 스위치의 순간 동작 대신 평균 전압으로 AC단을 계산함. 실제 스위칭·소자 전환은 미포함.

**dq-PI**: dq 좌표계 전류오차를 비례·적분 연산하는 기본 제어. 이번 개선에서는 기본 이득을 유지함.

**SOGI-PLL**: SOGI로 직교 신호를 만들고 PLL로 계통 위상을 추정함. PLL 설계값 20 Hz ≠ 검증된 전체 대역폭.

**전향보상 (FF)**: 계통전압과 기준 L/R값으로 필요한 전압을 미리 계산함. 전류오차 피드백과 별도의 경로임.

**준공진 피드백**: 선택한 고조파 주파수 부근의 전류오차에 이득을 부여함. 3·5·7차는 150·250·350 Hz에 대응.

**Kr [Ω] / fc [Hz]**: 공진 이득 / ωc=2πfc로 쓰는 준공진 대역 파라미터. fc는 계통 주파수나 전체 대역폭이 아님.

**teq / Iz**: 잔류 전압오차 크기를 정하는 등가 시간 / 전류 전환폭. teq는 실측 dead-time이 아닌 보정값.

### 4. 분석과 제어 조합 선정 (슬라이드 39쪽)

**DOE (실험계획법)**: 인자 수준의 조합을 계획해 반응값을 비교하는 방법. 이번에는 3인자×각 3수준의 27개 조합.

**인자 / 수준 / 반응값**: 변경할 변수 / 그 변수의 설정값 / 관측 결과. 예: Kr / 8·16·24 Ω / THD.

**가인자**: 영향 가능성과 변경 가능성을 검토할 후보 인자. 최종 원인으로 확정되었다는 뜻은 아님.

**완전요인배치**: 선택한 모든 인자 수준 조합을 빠짐없이 계산함. 27조합×9조건=243회, 243반복이 아님.

**주효과**: 다른 조건을 동일 가중한 수준별 평균 반응의 차이. 선택한 범위의 효과이며 p-value가 아님.

**교호작용**: 한 인자의 효과가 다른 인자의 수준에 따라 달라짐. 선이 교차해야만 생기는 것은 아님.

**대응 비교**: 동일 조건 ID의 초기·개선 결과를 짝지어 차이를 계산함. 대응 t-검정을 수행했다는 뜻은 아님.

**제곱합 / 기여도**: 평균에서의 편차 제곱합 / 총제곱합 중 요인별 비중. 제품 불량 원인 또는 제조 산포 비율이 아님.

### 5. 검증과 판정 (슬라이드 40쪽)

**잠정 설계기준**: 본 수치연구에서 사용한 판정 한계. 고객 확정 규격과 구분함. THD≤5%와 보조 조건은 모두 연구 가정.

**보조 조건 / 종합 만족**: P·Q 추종, 전류·포화·주기성 / THD와 보조 조건 전부 만족. THD 만족만으로 종합 만족을 뜻하지 않음.

**포화 시간비 [%]**: 전압 명령이 ±0.95Vdc 제한을 넘은 시간 표본의 비율. 전체 0.2 s 평가 구간을 분모로 계산함.

**주기성 오차 [A]**: 연속 두 주기의 전류 파형을 같은 위상끼리 빼고 RMS 계산. 작아도 전체 폐루프 안정성이 증명되지 않음.

**LHS (라틴 초입방체 표본화)**: 가정한 각 입력범위를 나누어 넓게 다루는 조건 생성법. 48개 LHS+12개 경계값 검증조건; 제조 분포 아님.

**초기값 보정 / 모델 검증**: 출력 크기를 기준값에 맞춤 / 실물과의 일치성을 확인함. 단일 THD 보정은 실물 검증을 대체 못함.

**수치 검증 / 회귀시험**: 계산 정확도 확인 / 변경 뒤 기존 시험의 재실행. 회귀시험은 회귀분석과 다른 말임.

**강건성 (Robustness)**: 가정·부품·환경이 달라져도 성능이 유지되는 성질. 60개 조건의 만족률은 현장 신뢰도가 아님.

### 6. 통계 용어의 해석 (슬라이드 41쪽)

**기술통계**: 주어진 데이터의 평균·최대·비율 등을 요약하는 계산. 모집단의 성능 보증 또는 가설검정과 구분함.

**Gage R&R**: 반복 측정과 측정자 차이 등 계측 변동을 분리하는 분석. 본 과제는 실제 반복 계측자료가 없어 미적용.

**ANOVA (분산분석)**: 반응 변동을 요인과 오차로 나누어 효과를 분석하는 방법. 본 과제는 제곱합 분해만, F검정은 미수행.

**자유도 (df)**: 제약을 반영한 독립 정보 수. 27개 평균의 총자유도는 26. 모든 요인항을 쓰면 남는 오차 자유도는 0.

**F값 / p-value**: 효과와 오차의 비 / 귀무가설하에서 결과의 극단성 지표. 본 과제 미산출. p는 귀무가설이 참일 확률이 아님.

**신뢰구간**: 정한 표본추출·오차 모형에 근거해 모집단 값을 추정하는 구간. 시뮬레이션 조건 범위나 최소·최대와 다름.

**Cpk / Z.Bench**: 공정 산포와 규격의 관계를 요약하는 공정능력 지표. 제품·공정 산포가 없는 이번 자료에 미적용.

**층별 분석 / 범주형 인자**: 조건별 그룹으로 나눔 / 수치간 거리보다 종류로 구분하는 인자. 차수 조합은 범주형. 3→5→7의 선형효과로 보지 않음.

### 7. 수치계산·구현·검증 기록 (슬라이드 42쪽)

**Ts / fs**: 제어·저장 주기 31.25 μs / 주파수 32 kHz. Ts=1/fs. 수치 적분 시간간격 Ts/8과 구분함.

**RK4 / 적분 시간간격**: 상태방정식을 4차 Runge–Kutta로 계산 / 한 계산의 시간간격. 간격 세분화 비교는 수치오차 확인용임.

**FFT / 정수주기 구간**: 파형을 주파수 성분으로 분해 / 기본파의 정수 주기를 포함한 구간. 본 계산은 50 Hz의 10주기 0.2 s, 6,400표본.

**ADC / 양자화 / DSP**: 아날로그-디지털 변환 / 값의 눈금화 / 제어 연산 프로세서. 양자화는 모델 가정, DSP 실행시간은 미검증.

**DC-link / CLLC**: DC 중간단 / 양측 공진소자를 갖는 DC-DC 전력변환단. Vdc를 고정 입력으로 쓰므로 해당 동특성 미포함.

**DCM / Coss**: 전류 불연속 도통 모드 / 전력반도체 출력 커패시턴스. 실제 전환·비선형성은 본 모델에서 미검증.

**정착시간**: 지령 변경 후 이동평균 전력 오차가 한계 내에 들어와 유지되기까지. 과도응답 정의와 보조 주기성 판정은 다른 항목.

**해시 (SHA-256)**: 파일 바이트에서 계산하는 식별값. 원자료 변경 여부 확인용. 같은 해시가 물리적 모델 정확도를 보증하지 않음.

## 8. 실행 수의 구성과 제외 원칙

주연구571회 = DOE243 + 기준 초기·개선126 + 변동 초기·개선120 + 공개자료 비교18 + 범위 외 초기·개선30 + 오차항 진단10 + Vdc 진단9 + 과도응답8 + 시간간격 비교5 + 해석시간 비교2이다. 모델 구조 검토30회를 더하면601회이다. 기준값 보정12회 및 수치 검증 항목 수와는 별도이다. 이 수를 독립 시료601개로 표현하지 않는다.

V4는 위 성능 시뮬레이션을 새로 수행한 버전이 아니다. 원자료의24개 자동검사, 제곱합·전이표·하위집합 재계산, 보고서와 원자료 정합검사를 수행한 문서 개정이다. 실물 파라미터·고객 기준·사내 제출 인정 범위는 아직 미확인이다.
