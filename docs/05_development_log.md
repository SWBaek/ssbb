# 05. 수치모델 개발 중 수정 기록

성능 DOE 실행 전 수치 verification에서 발생한 문제를 보존한다. 아래 내용은 실제 작성/실행 중 발견한 오류이며, 최종 결과의 경험적 타당성을 증명하는 자료는 아니다.

| 점검 | 초기 상태 | 수정 | 최종 상태 |
|---|---|---|---|
| 비선형 한 제어구간 해와 독립 DOP853 비교 | RK4 8분할 최대 오차 약 2.824 mA로 1 mA 기준 미달 | production RK4 16분할로 변경 | 최대 약 0.3852 mA, 기준 통과 |
| 평균 전력수지 | command ZOH 경계에서 단순 좌측 합산 시 약 3.48 W 잔차 | 구간별 고정 command와 양 끝 전류로 trapezoid, 인덕터 에너지 변화 포함 | 약 0.0090 W, 0.5 W 기준 통과 |

pass threshold를 바꾸거나 응답에 noise를 더해 통과시킨 것이 아니다. 모델 개발 과정의 smoke test는 독립 성능 입증 표본으로 세지 않는다. 최종 성능 실행 591회와 numerical verification 실행은 별도다.
