# 04. 최종 논리 검토

검토 주체: 동일 작성 에이전트의 별도 검토. 독립 심사자 또는 MBB 승인으로 표현하지 않는다. 기존 11개 자료의 관련 장을 원문으로 확인했으며, 해당 자료의 모든 통계 결과를 재계산하거나 합격 승인 기록을 검증한 것은 아니다. 참조 대응은 `reference_cases.json`에 있다.

## 제거한 논리적 과장

| 점검 | 처리 |
|---|---|
| 가상 baseline을 실제 현수준으로 표시 | 모든 산출물에서 참조모델 baseline으로 표시 |
| THD 5%를 고객/IEEE 확정 규격으로 간주 | 잠정 설계 가정으로 고정, 실제 규격 확정은 미완료 |
| 목표를 정하고 그에 맞는 데이터 작성 | 회로 미분방정식을 실제 적분; 원시 파형과 코드 제공 |
| 선택/평가 데이터 혼용 | 72점 중 학습 9점과 나머지 63점을 별도 보고; 72개 추가 stress 조건 분리 |
| 동일 모델의 역함수 보상만으로 현실성 주장 | 보상은 지령전류와 고정 추정값 사용; true td/함수 형상을 holdout에서 변경. 실측 검증 대신이라고 하지는 않음 |
| holdout 미달을 보고 재튜닝 | 선택 설정 hash를 실행 전후 대조; 실패 모두 보존 |
| 가짜 반복·Gage R&R·정규성·p-value·Cpk | 결정론적 factorial 효과크기와 교호작용만 제시; 제조 통계로 해석하지 않음 |
| THD가 낮으면 최종 채택 | H037은 THD 통과라도 포화 기준 위반으로 combined fail |
| 부작용 없음 주장 | T1 정착시간 증가와 포화 사례를 보고; 열/효율/전체계통은 미검증 |
| 수치 검증을 실물 검증으로 대체 | verification과 empirical validation을 분리 |
| 기존 합격 사례로 이번 합격 보장 | 사내 승인 근거가 없으므로 BB 승인 여부는 미확인 |
| 금전 효과 부풀리기 | 실측 공수·지출 자료 부재로 재무성과 미산정 |

## 미해결 기술/업무 경계

1. **모델 적용성:** 실제 totem-pole Q 운전 영교차 문제를 모델링하지 않았다. 일정 S에서 위상만 바꾼 결과도 Q 고유 원인이라고 단정할 증거가 아니다. 따라서 상위 과제 전체의 현장 원인 해결은 아직 입증하지 못했다.
2. **실측 부재:** 회로값, dead-time 등가식, 검출 오차는 가정이다. 상용 도구와 결과가 같아도 두 모델이 함께 현실과 다를 수 있다. 과거 제품 데이터 또는 HW 시험으로 별도 검증해야 한다.
3. **조건부 개선:** 주 행렬의 100%와 stress 조건의 미달을 함께 보고한다. stress 결과는 생산 합격확률이 아니다. 부품의 실제 공차/상관/분포를 추정한 데이터가 없다.
4. **완료 기준:** customer CTQ·운전영역·제품 적용 범위·BB 승인 조건 미확정. 보고서 형식이 갖춰졌다는 이유만으로 사내 완료라고 할 수 없다.
5. **제어안 한계:** 최고 후보 bw에서 선택되었지만 실제 폐루프 대역폭·위상여유·소신호 안정도 분석 또는 MCU 실행시간을 측정하지 않았다. 잠정 calibration 제안이지 제품 투입 허가가 아니다.

## 후속 변경 원칙

재현할 때 계산 결과가 달라도 이전 데이터를 지우거나 숫자만 수정하지 않는다. 모델/측정/기준이 바뀌면 새 study revision을 만들고 전체 행렬을 재실행한다. 현재 holdout을 이용하여 개선안을 바꾸는 경우 그 72점은 더 이상 미사용 검증셋이 아니므로 새로운 검증셋을 지정한다.

## 검토 판정

**조건을 명시한 수치 연구로서 근거를 연결했다. 실제 제품/규격/사내 BB 과제 전체의 완료 근거로는 아직 부족하다.** 가장 큰 잔여 문제는 통계 도구의 개수가 아니라 실제 무효전력 왜곡 메커니즘과 참조 모델의 대응이다.
