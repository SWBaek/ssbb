# 06. 산출물 품질 점검

최초 실행 환경에서 다음을 실제 확인했다.

- 수치 verification: 23개 통과. 이는 모델의 경험적 타당성 인증이 아니다.
- 코드/데이터 계약 테스트: 20개 통과. 591개 실행 모두의 NPZ 저장 파형으로 1~40차 RMS와 THD를 다시 계산하여 결과표와 대조했다.
- 31장 HTML: Chromium에서 렌더링, 1366 px 화면에서 모든 슬라이드의 본문/각주 겹침 및 잘림 검사 통과.
- 방향키 이동, 전체 보기 전환, 목차 이동 및 JavaScript 실행 오류 검사 통과.
- 412 px 화면: 요약 슬라이드 렌더링과 가로 넘침 없음 확인. 실제 모든 종류의 모바일 브라우저를 시험한 것은 아니다.
- 사내 PPTX 원본이 저장소 작업 사본에 포함되지 않음을 자동 검사했다.

HTML의 수치 표와 그림은 저장된 수치 결과에서 생성했다. 문서 논리 검토는 동일 에이전트가 수행했으며 독립 심사자/MBB 승인은 포함되지 않는다.
